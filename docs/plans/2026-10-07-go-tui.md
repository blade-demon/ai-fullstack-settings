# Go TUI 迁移计划

目标：使用 Go + Bubble Tea / Bubbles / Lip Gloss 替换成员交互菜单，提供阶段状态、滚动日志、确认、取消与返回；双击和 npx 使用相同界面。现有 Bash 安装模块及卸载安全边界保留，命令行参数和 --plain 提供无界面执行。

界面：主菜单覆盖 Java 一键、JDK 8、Gradle 4.5.1/6.8、IDEA、IDEA 插件、前端子菜单、卸载；方向键/Enter、Esc 返回、q 退出。安装先确认，再在运行页显示阶段和日志；不能计算真实比例时显示进行中而不是伪造百分比。启动只读检查失败显示待配置，不阻止菜单。

卸载：TUI 提供预览和进入安全卸载流程；通过 Bubble Tea ExecProcess 暂停界面，将终端交给现有卸载器，保留 IDEA 范围选择、原计划复核与 DELETE 确认，返回后显示状态。不得新增 --apply --yes 绕过确认。

接口：

- Go 模块目录 tui/，package main。UI 使用 Action{ID,Title,Description,Args,Interactive}，Args为相对 .support 的脚本路径及参数，/bin/bash按参数数组执行。
- ActionsFor(page string) []Action，页面 home/gradle/frontend/cleanup；子菜单 Action 的 ID 为 page:xxx。
- Runner{SupportDir string,LogRoot string}；Start(Action) (*Job,error)。Job{Events <-chan Event,LogPath string}、Cancel()。Event{Kind,ID,Title,Status,Line string,Code int}，Kind 为 log/stage/done。交互任务通过独立命令交给 ExecProcess，不进入后台Runner。
- Event协议：仅 TEAM_TUI_EVENTS=1 时 Bash 输出 `@@TEAM_TUI\tstage\tID\tSTATUS\tTITLE`；STATUS为running/succeeded/failed/pending。普通输出作为日志；UI不解析自然语言判断成功。
- Runner通过独立进程组取消子进程及后代，先INT，超时再TERM/KILL，等待退出；退出/失败/取消准确区分，完整日志写入用户日志目录，内存日志有上限。
- TUI CLI：--support-dir PATH --page home|frontend|cleanup，--help/--version；无TTY提示使用 --plain，不自动执行安装。
- 产物 resources/tui/team-dev-env-arm64、team-dev-env-amd64、manifest.json、THIRD_PARTY_NOTICES.txt；CGO_ENABLED=0分别编译darwin架构，成员无需Go。包内映射为 .support/tui/ 同名文件。
- manifest schema=1，source_sha256，binaries={arm64:{file,sha256},amd64:{file,sha256}}。源码hash对tui/下.go、go.mod、go.sum按相对路径排序，将路径UTF8+NUL+规范化LF内容+NUL串联做SHA256，包含测试代码避免过期产物。
- 公用 run-tui.sh 选择架构、校验清单/可执行文件后启动；run-cleanup.sh 为旧卸载入口的无UI执行层，避免递归。安装/卸载双击默认TUI；--plain或既有明确CLI参数继续走原流程；--frontend单独参数且TTY时打开前端页面。
