# Gradle 版本菜单实施计划

目标：仅提供 JDK 8，Gradle 可选择 4.5.1 / 6.8；一键安装固定使用用户确认的 JDK 8 + Gradle 4.5.1，并包含 IDEA 和六个推荐插件。

设计：复用原扫描、安装、验证和历史流程，以 Gradle 版本参数选择独立目录和安装包。GRADLE_HOME 指向本次选择，保留各版本别名；两个版本均使用 JDK 8。IDEA 显示当前用户实际 Applications 目录。

- [x] 官方资源：增加准确 Gradle 6.8 的固定 URL、SHA-256 与来源。
- [x] 受管环境：分别写入 GRADLE_4_5_1_HOME / GRADLE_6_8_HOME，保留已有别名，检查新终端加载。
- [x] Gradle 安装：覆盖 6.8 下载、复用、校验失败、版本切换与实际构建；保留 4.5.1 兼容。
- [x] 菜单及修复入口：支持菜单 3 的版本选择、直接输入 3.1 / 3.2、取消与 EOF；菜单 2 直接安装 JDK 8。一键安装固定 4.5.1。
- [x] 集成：同步说明，运行相关与完整回归、脚本语法检查，并独立复查。

验证使用临时 HOME、微型 SDK 与本机 HTTP 资源，不安装到用户真实软件目录。保留此前菜单精简改动，不创建提交或发布分发包。

验证结果：377 项全量回归通过；随后新增的 Gradle 6.8 完整修复流程测试单独通过；25 个 Shell 脚本语法检查与独立代码复查通过。
